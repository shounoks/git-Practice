# Git Practice

This repository is created for practicing Git and GitHub.

## What I Learned

- Git is a version control system.
- GitHub is a platform for hosting Git repositories.
- A repository stores project files and their history.
- A branch allows us to work on changes separately.
- A commit saves changes to the Git history.
- A Pull Request allows us to propose changes to another branch.

## Basic Git Commands

- `git clone` - Clone a repository to the local computer.
- `git status` - Check the current status of the repository.
- `git branch` - List branches.
- `git switch` - Switch between branches.
- `git add` - Stage changes.
- `git commit` - Save staged changes.
- `git push` - Upload local commits to GitHub.
- `git pull` - Get updates from the remote repository.

## Git Workflow

1. Clone the repository.
2. Create a feature branch.
3. Make changes.
4. Stage and commit changes.
5. Push the branch to GitHub.
6. Create a Pull Request.
